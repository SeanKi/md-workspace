## 쓰는 법

| 하는 일 | git 으로 치면 | 어디서 |
|---|---|---|
| 있는 저장소에 원격 붙이기 | `git remote add` + 첫 `push` | 저장소 머리 → **원격 연결** |
| 원격에서 가져오기 | `git clone` (단, 목록만) | 사이드바 위 **☁ 가져오기** — 로컬 캐시 폴더를 꼭 고른다 |
| 맞추기 | `pull` + `push` | 저장소 머리 **⟳** · 저장할 때 그 문서만 · 설정의 간격마다(기본 120초) |
| 받지 않은 문서 열기 | — | 트리의 ☁ 를 누르면 그 문서만 받는다 |
| 지우기 | `git rm` + `push` | 트리에서 지운 것만 원격에서도 지운다 |

Koofr: 주소 `https://app.koofr.net/dav/Koofr/<폴더>` · 사용자 = 로그인 이메일 ·
비밀번호 = Koofr 설정의 **앱 비밀번호**. 비밀번호는 INI 가 아니라 **Windows 자격 증명 관리자**에 있다.

## 로컬은 캐시다 (계획서와 달라진 점 ①)

원격을 등록할 때 로컬 캐시 폴더를 함께 정한다. **한꺼번에 내려받지 않는다.**

- 트리는 원격의 문서 목록(catalog)으로 그린다 — 받지 않은 것은 ☁ (흐리게)
- 문서를 열 때 그 문서만 받는다. 맞출 때 오가는 것은 **캐시에 있는 문서**뿐이다
- 캐시 폴더에서 파일이 없어진 것은 지운 것이 아니다 → ☁ 로 돌아간다. **트리에서 지운 것만** 원격에서도 지운다
- 옮기기·이름 바꾸기는 받아 둔 것만 따라간다 (☁ 는 옛 자리에 남는다 — 사라지지는 않는다)

## 원격의 모양 — 서버 기능에 기대지 않는다 (달라진 점 ②)

```
<원격>/폴더/a.md                              사람이 읽는 거울 (동기화는 읽지 않는다)
<원격>/.mdsync/devices/<기기>/index.json        그 기기가 올린 문서들의 판 번호
<원격>/.mdsync/devices/<기기>/docs/<키>.json     문서의 지금 판 — 블록 목록 [[id, hash, 원문]] · 누가 · 언제
<원격>/.mdsync/devices/<기기>/hist/<키>/<판>.json  이력 — 덮어쓰지 않는다
```

**기기는 자기 이름의 폴더에만 쓴다.** 여럿이 같은 파일을 덮어쓰지 않으니 서버에 조건부
쓰기(`If-Match`)나 잠금이 없어도 된다 — Koofr 처럼 무엇을 지원하는지 알 수 없는 서버도.
계획서의 "공유 매니페스트 + ETag" 를 버린 이유다.

블록마다 파일을 따로 두지 않고 **문서 하나에 파일 하나**다 — 블록마다면 노트 760개를 처음
올릴 때 요청이 15,000번이다. 병합은 그래도 블록 단위다.

`store` 는 다섯 가지만 한다: `get · put · del · list · mkdirs` (`remote.js`). **FTP 는 같은 다섯
가지를 하는 클라이언트를 하나 더 만들면 된다** (`apps/md-tiptap/src/sync/adapter.js` 의 `storeFor`).

## 병합 — 블록 단위 3-way

| 상황 | 결과 |
|---|---|
| 한쪽만 고친 블록 | 고친 쪽 |
| 서로 다른 블록 | 둘 다 |
| 같은 블록의 다른 줄 | 줄 단위로 합친다 (diff3) |
| 같은 줄을 둘 다 | 한 판을 남기고 다른 판을 **충돌 인용**으로 바로 아래에. 어느 쪽이 남는지는 내용 해시로 정해 두 기기가 같은 결과를 낸다 |
| 지움 vs 그대로 | 지운다 · 지움 vs 고침 → **고친 것이 산다** |

공통 조상(base)은 두 후보 중 나중 것: ① 그 기기 판 중 내가 마지막으로 합친 것
② 내 판 중 그 기기가 마지막으로 합친 것(`seen`). ② 를 빼면 상대가 이미 받아 간 내 고침을
새 고침으로 오해해 옛 블록이 되살아나거나 충돌이 불어난다 — 시험으로 확인했다.

블록 ID 는 파일에 쓰지 않는다. 지난번 목록과 해시 LCS 로 맞추고, 같은 자리에 하나 빠지고
하나 들어왔으면 "고친 것" 으로 이어받는다. 문서 끝 줄바꿈은 따로 둔다 — 마지막 문단에 붙여
두면 끝에 덧붙일 때마다 마지막 문단이 고친 것이 되어 괜한 충돌이 났다.
